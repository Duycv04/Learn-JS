## Hướng dẫn học

1. Bắt đầu từ các khái niệm cơ bản như biến, kiểu dữ liệu, điều kiện, vòng lặp.
2. Học các cấu trúc như function, array, object.
3. Nắm các kỹ thuật nâng cao như destructuring, spread/rest, closure và callback.
4. Chạy các file `.js` mẫu để luyện tập thực tế.

## Gợi ý

- Đọc file `readme.md` trong từng folder trước.
- Chạy file JavaScript tương ứng bằng Node.js.
- Thử sửa đổi ví dụ để hiểu sâu hơn về cách hoạt động.
