## Lộ trình học gợi ý

1. Học biến và kiểu dữ liệu
2. Nắm rõ câu lệnh điều kiện
3. Hiểu vòng lặp
4. Tìm hiểu hàm
5. Làm quen với mảng và object
6. Làm bài tập thực hành

## Mẹo học hiệu quả

- Viết lại từng ví dụ bằng tay
- Đừng chỉ đọc, hãy chạy code trên trình duyệt hoặc Node.js
- Tập giải thích từng dòng code bằng ngôn ngữ của bạn
- Học theo chủ đề, không học lan man

## Kết luận

JavaScript là ngôn ngữ mạnh mẽ và rất phổ biến. Nếu bạn nắm được nền tảng cơ bản như biến, hàm, mảng và object, bạn sẽ dễ dàng học các chủ đề nâng cao hơn như DOM, ES6, Async/Await, API,...
