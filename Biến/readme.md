Variable - Biến :
var : Có thể gán lại giá trị, khai báo lại cùng tên , Block scope {} không cần, function scope có
let : Có thể gán lại giá trị, không được khai báo lại cùng tên, Block scope {} có, function scope có
const : Không thể gán lại giá trị, không khái báo lại cùng tên, Block scope {} có, function scope có
